## Key Enhancements from Original MVP

- Keyword / search term input mode (DuckDuckGo HTML + follow-up analysis)
- Two additional professional tasks: `meta` and `tables` (pandas.read_html)
- Complete modular separation (scraper.py)
- Dedicated Streamlit dashboard (the project name now makes full sense)
- Fixed + dramatically improved downloads, views, and UX
- Robust auth proxy
- Proper env configuration examples

## Quick Local Commands

```bash
# Python backend
cd python-backend && python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
uvicorn main:app --reload --port 8000

# Netlify
netlify dev

# Streamlit companion
cd streamlit-app && pip install -r requirements.txt && streamlit run app.py
```
